
제작기간 制作期間 : 2025.11 ~ 2025.12

名前 : シェアタイム SHARE TIME

チーム : SHM(Leader / 本人), KHM, OYG, HJE

사용 툴 ツール : HTML / CSS / JavaScript / Firebase / Firestore

파트 パート（本人担当）:
- チームリーダーとしてスケジュール管理・会議進行を担当
- Firebaseを活用したリアルタイムチャット機能の実装
- 再接続後もチャット履歴が保持されるようFirestoreのデータ設計を工夫
- 通知機能の実装
- コミュニティ機能の実装


制作目的 :
개인 간 중고거래에서 파생된 시간을 거래해 재능을 공유함. 내 재능을 공유하며 타인의 재능을 공유받는 서비스 
ユーザーが提供できるスキルと求めるスキルを登録し、
同じ地域のユーザー同士がマッチングしてスキルを交換できるサービス。
個人間で時間と才能を共有し、お互いの強みを活かし合うことを目指した。
